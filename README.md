# Safe Travels - Mobile

## Introdução

Repositório destinado ao registro da elaboração do Trabalho de Conclusão de Curso (TCC) de Sistemas de Informação do aluno Vicente Hofmeister pela Pontifícia Universidade Católica do Rio Grande do Sul (PUCRS).

Este trabalho propõe o desenvolvimento de um sistema colaborativo para compartilhamento de dados de localização em tempo real durante viagens em grupo, enfrentando limitações de conectividade e garantindo maior segurança e privacidade na integração das informações.

O presente repositório serve para registro e desenvolvimento da aplicação mobile. Para acompanhar o desenvolvimento da API assim como a Wiki, acesse os respectivos repositórios:

- [Safe Travels - API](https://github.com/vicente-hofmeister/Safe-Travels-API)
- [Safe Travels - Wiki](https://github.com/vicente-hofmeister/Safe-Travels-Wiki)

## Configuração local

Para testar no Expo com o servidor rodando na sua máquina, ajuste a variável `EXPO_PUBLIC_API_URL` no arquivo `.env` para o IPv4 da sua rede local com a porta do backend.
